# Project 3

**Name:** Evode Manirahari  
**Course:** CS 351

This project uses WebGL shaders to procedurally generate simple shapes.

## Versions

1. [Wireframe Triangle](triangle.html)  
   Draws an equilateral triangle using `gl.LINE_LOOP`.

2. [10-Sided Filled Polygon](polygon.html)  
   Uses `gl.TRIANGLE_FAN` and 12 vertices to draw a filled 10-sided polygon.

3. [Five-Pointed Star](star.html)  
   Alternates the radius of vertices to create a five-pointed star.

4. [Rotating Five-Pointed Star](rotating-star.html)  
   Adds a time uniform `t` to rotate the star.

5. [Colorful Rotating Star](colorful-rotating-star.html)  
   Extra credit version. Passes the radius from the vertex shader to the fragment shader to create interpolated colors.
